# Mouse Movement Tracker & Bot Detection (Applied Geometry)

פרויקט יישומי בקורס **גיאומטריה יישומית** לחקר וזיהוי דפוסי תנועת עכבר אנושיים מול בוטים מבוססי מודלים מתמטיים וגיאומטריים.

---

## 📌 סקירת הפרויקט
המערכת דוגמת ומקליטה מסלולי תנועת עכבר בקצב גבוה (כל 5 מילישניות) בין נקודת התחלה (עיגול ירוק) למטרה (עיגול אדום). במקביל, המערכת כוללת מחולל של שלושה סוגי בוטים:
1. **Linear Bot (`bot_linear`)** – תנועה בקו ישר ובמהירות אחידה.
2. **Curved Bot (`bot_curved`)** – תנועה חלקה לאורך עקומת בזייה ריבועית (Bézier).
3. **Noisy Bot (`bot_noisy`)** – תנועה המשלבת סטיות אקראיות רציפות ותיקון הדרגתי ליעד.

המסלולים מנותחים גיאומטרית (אורך דרך, יחס ישרות, שינויי כיוון מצטברים, מהירויות, ועקמומיות מקומית באמצעות התאמת פולינום בחלון נע) לצורך השוואה ופיתוח מנגנון סיווג שמבדיל בין אדם לבוט.

## 🚀 הוראות הרצה

### 1. הפעלת מערכת האיסוף והבוטים:
```bash
python3 mouse_tracker.py
```
* לחצו על העיגול הירוק כדי להתחיל תנועה אנושית, והזיזו את העכבר אל העיגול האדום.
* לחלופין, השתמשו בכפתורי הבוטים בממשק (`Linear Bot`, `Curved Bot`, `Noisy Bot`) ליצירת תנועות אוטומטיות בזמן אמת.

### 2. הפעלת ניתוח הנתונים והפקת הסיכום:
```bash
python3 analyze_trajectories.py
```
הסקריפט יקרא את כל קובצי ה-CSV בתיקיית `data/` ויעדכן את הטבלה המסכמת `geometry_summary.csv`.

### 3. הרצת בדיקות יחידה:
```bash
python3 -m unittest test_analyze_trajectories.py test_mouse_bots.py
```

## 📊 המדדים הגיאומטריים המרכזיים
* **`path_length` & `direct_distance`**: אורך המסלול בפועל מול המרחק האוקלידי הישיר.
* **`path_ratio`**: היחס בין אורך הדרך למרחק הישיר (מדד ישרות).
* **`total_angle_change`**: סך שינויי הזווית ברדיאנים לאורך המסלול (מדד חלקות).
* **`mean_curvature` & `p95_curvature`**: אומדן עקמומיות מקומית באמצעות התאמת פולינום מעלה 3 בחלון נע (Local Polynomial Fitting) תוך טיפול בהיפוכי כיוון.
* **`mean_speed_px_s` & `stationary_interval_s`**: מהירות ממוצעת וזמני השהייה.
