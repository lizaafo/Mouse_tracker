# Mouse Movement Tracker & Bot Detection (Applied Geometry)

מערכת מחקר וזיהוי תנועות עכבר אנושיות מול בוטים מבוססי מודלים מתמטיים, קינמטיים וגיאומטריים, במסגרת הקורס **גאומטריה יישומית**.

---

## 📌 סקירת הפרויקט ומטרתו

הפרויקט חוקר את היכולת להבחין בין תנועות עכבר של משתמשים אנושיים לבין בוטים אוטומטיים בממשקי משתמש (הגנת בוטים / CAPTCHA התנהגותי), על בסיס **גאומטריה דיפרנציאלית** ו**קינמטיקה מוטורית**.

המערכת כוללת:
1. **ממשק איסוף גרפי (GUI)** מבוסס Tkinter לדגימת תנועה אנושית בקצב גבוה (דגימה כל ~5ms ואירועי חומרה).
2. **מחולל בוטים מובנה** בעל 6 מודלים מתמטיים שונים ברמות תחכום עולות (מודלים נאיביים, מודלים ביומכניים, ובוט מתחזה אדברסריאלי).
3. **מנוע ניתוח גאומטרי וקינמטי** לחילוץ מדדי דרך, עקמומיות מקומית, חוק שני-השלישים, ג'רק חסר ממדים, עקביות אפינית, ושארית התאמה לבזייר.
4. **מנוע סיווג (Machine Learning)** מבוסס עצי החלטה ויערות אקראיים (Random Forest), הכולל שלושה מבחני ביצועים (Benchmarks): מודל מלא עם רעד וג'רק (100%), מודל גאומטרי טהור ללא ג'רק (94.7%-98.5%), ומבחן הכללה בין סשנים (Leave-One-Session-Out CV עם 94.0% ממוצע וניתוח שגיאות איכותני על תנועות אנושיות מהירות).
5. **ממשק הדגמה בזמן אמת (`live_demo.py`)** המסווג תנועות עכבר חיות בלייב ומציג רמת ביטחון מכוילת באחוזים.
6. **מערך ויזואליזציה** המפיק 5 גרפים מדעיים באיכות פרסום.

## 🤖 ששת סוגי הבוטים במערכת

המערכת מיישמת 6 מודלים שונים ליצירת תנועות אוטומטיות בזמן אמת:

| שם הבוט | מזהה מערכת | תיאור המודל המתמטי והקינמטי |
| :--- | :--- | :--- |
| **בוט ליניארי** | `bot_linear` | תנועה בקו ישר במהירות קבועה לחלוטין ($u = \tau$). |
| **בוט מעוקל** | `bot_curved` | תנועה לאורך עקומת בזייה ריבועית (Quadratic Bézier) עם נקודת בקרה בניצב למיתר, במהירות פרמטרית אחידה. |
| **בוט רועש** | `bot_noisy` | קו ישר עם הפרעות צידיות אקראיות רציפות (Smoothstep Interpolation) ותיקון הדרגתי ליעד. |
| **בוט Min-Jerk** | `bot_smart_jerk` | מסלול בזייה בשילוב מודל **Minimum Jerk** (Flash & Hogan, 1985) באמצעות פולינום מעלה 5: $u = 10\tau^3 - 15\tau^4 + 6\tau^5$, היוצר פרופיל מהירות פעמוני חלק עם האצה ובלימה. |
| **בוט ביומכני** | `bot_smart_full` | מודל מתקדם המשלב פרופיל מהירות א-סימטרי ($\tau^{0.8}$ – שיא מהירות מוקדם האופייני לתנועת יד אנושית), בלימה מוארכת, ורעידות נוירו-מוטוריות פיזיולוגיות (Tremor בתדרי 10Hz ו-18Hz). |
| **בוט מתחזה** | `bot_adversarial` | בוט יריב מתוחכם המצמד את המהירות לעקמומיות לפי חוק שני-השלישים ($v \propto \kappa^{-1/3}$) ומשלב מעטפת פעמון חלקה כדי להערים על מודלים נאיביים. |

## 🚀 הוראות הרצה

### 0. התקנת תלויות וסביבת עבודה:
```bash
pip install -r requirements.txt
```

### 1. הפעלת ממשק ההדגמה החי (מומלץ להדגמה):
```bash
python3 live_demo.py
```
* מאפשר הזזת עכבר חיה או הפעלת בוטים בלייב, ומציג באופן מיידי כרטיס החלטה עם רמת ביטחון וכל המדדים הגיאומטריים.

### 2. הפעלת ממשק איסוף הנתונים המקורי:
```bash
python3 mouse_tracker.py
```
* לוחצים על העיגול הירוק ומזיזים את העכבר אל העיגול האדום, או לוחצים על אחד מ-6 כפתורי הבוטים לשמירת ניסיונות חדשים ל-`data/`.

### 3. הרצת מנוע החישובים הגיאומטריים:
```bash
python3 analyze_trajectories.py
```
* סורק את כל קובצי ה-CSV, מחשב את כל 11 המדדים, ומעדכן את `geometry_summary.csv` (132 מסלולים מאומתים לאורך 9 סשנים).
* להרצת בדיקת תקינות גאומטרית על מסלולים סינתטיים (קו ישר וקשת מעגלית):
  ```bash
  python3 analyze_trajectories.py --validate
  ```

### 4. הרצת מודל הסיווג והערכה מדעית (Machine Learning):
```bash
python3 classify_trajectories.py
```
* מריץ ומציג **שלושה מבחני ביצועים (Benchmarks)** נפרדים:
  * **Benchmark A (מודל מלא עם Jerk):** מגיע ל-100% דיוק ומדגים את השפעת הרעד השרירי הפיזיולוגי בתדר גבוה.
  * **Benchmark B (מודל גיאומטרי טהור ללא Jerk):** הערכה מציאותית של גיאומטריה מרחבית ופרופילי מהירות מאקרו (94.7%-98.5% דיוק).
  * **Benchmark C (הכללה בין סשנים – Leave-One-Session-Out):** בדיקה על סשנים חדשים לחלוטין (94.0% ממוצע) כולל ניתוח שגיאות איכותני המבודד תנועות אנושיות מהירות (Flicks) המחקות עקומות בזייה.

### 5. הפקת גרפי הוויזואליזציה:
```bash
python3 visualize_results.py
```
* מייצר 5 גרפים בתיקיית `plots/` הממחישים את ההבדלים הגיאומטריים והקינמטיים, כולל עץ החלטה עם כל 11 התכונות.

### 6. הרצת חבילת בדיקות היחידה המלאה (כל 27 הבדיקות):
```bash
python3 -m unittest discover -v
# או ישירות לפי שמות הקבצים:
python3 -m unittest test_analyze_trajectories.py test_mouse_bots.py test_live_demo.py
```

## 📐 המדדים המרכזיים בטבלת הסיכום (`geometry_summary.csv`)

| קטגוריה | שם המדד | תיאור ומשמעות גאומטרית / קינמטית |
| :--- | :--- | :--- |
| **ישרות ודרך** | `path_length` | אורך המסלול הגולמי המצטבר בפיקסלים ($\sum \Delta s$). |
| | `direct_distance` | המרחק האוקלידי הישיר בין נקודת ההתחלה לסיום. |
| | `path_ratio` | יחס הישרות: $\frac{\text{path\_length}}{\text{direct\_distance}}$ (1.0 לקו ישר מושלם). |
| | `max_chord_dev_px` | הסטייה המקסימלית בפיקסלים מהמיתר הישיר המחבר התחלה לסיום. |
| | `bezier_residual_px` | שארית התאמה גאומטרית מרחבית טהורה לעקומת בזייר ריבועית אופטימלית ($\approx 0-3\text{px}$ בבוט, $\approx 8-20\text{px}$ באדם). |
| **עקמומיות** | `mean_curvature` | ממוצע העקמומיות המקומית ($\kappa = \frac{\|\dot{\gamma} \times \ddot{\gamma}\|}{\|\dot{\gamma}\|^3}$) ביחידות $1/\text{pixel}$. |
| | `max_curvature` / `p95_curvature` | ערכי שיא ואחוזון 95 של העקמומיות לאורך המסלול. |
| | `curvature_std` | סטיית התקן של העקמומיות (מבדילה בין קשת חלקה לשונות אנושית). |
| | `curvature_coverage_pct` | אחוז אורך המסלול שבו העקמומיות חושבה בצורה תקפה (ללא קצוות/היפוכים). |
| **קינמטיקה וזמן** | `duration_s` | משך התנועה הכולל בשניות. |
| | `mean_speed_px_s` | מהירות ממוצעת לאורך המסלול. |
| | `peak_to_mean_speed` | יחס שיא המהירות למהירות הממוצעת: $\approx 1.0$ בבוט מהירות אחידה, $\approx 1.88$ ב-Min-Jerk, $\approx 2.5-6.0$ באדם. |
| | `time_to_peak_ratio` | תזמון שיא המהירות כאחוז ממשך התנועה ($\approx 25\% - 45\%$ באדם). |
| | `log_dimensionless_jerk` | ציון ג'רק חסר ממדים מנורמל בזמן ומרחק: $\log_{10} \left( \int \|\dddot{x}\|^2 dt \cdot \frac{T^5}{L^2} \right)$. |
| | `stationary_interval_s` | סך זמני השהייה שבהם העכבר לא זז (אופייני לעצירות תיקון אנושיות). |
| **חוק שני-השלישים** | `power_law_beta` | מעריך חוק שני-השלישים ($\ln v = C - \beta \ln \kappa$). באדם $\beta \approx 0.33-0.45$, בבוטים נאיביים $\beta \approx 0.0$. |
| | `power_law_r` | מתאם פירסון בין $\ln v$ ל-$\ln \kappa$ לאורך המסלול (שלילי מובהק באדם, אפסי בבוטים נאיביים). |
| | `affine_velocity_cv` | מקדם השתנות המהירות האפינית ($v_{aff} = \kappa^{1/3} v$). קבוע כמעט לחלוטין באדם. |
| **זוויות וכיוון** | `total_angle_change` | סך שינויי הזווית המצטברים ברדיאנים לאורך המסלול. |

## 🔬 רקע תיאורטי וחיבור לקורס גאומטריה יישומית

1. **פרמטריזציה לפי אורך קשת (Arc-Length Parameterization):**
   ב-[`analyze_trajectories.py`](analyze_trajectories.py), המסלול עובר דגימה מחדש (Resampling) ל-100 נקודות במרווחי אורך קשת אחידים $ds$, כך ש-$\|\gamma'(s)\| \approx 1$.
2. **התאמת פולינום מקומי וגזירה אנליטית:**
   במקום להשתמש בהפרשים סופיים רגישים לרעש, מותאם פולינום מעלה 3 בחלון נע של 7 נקודות באמצעות ריבועים פחותים (`np.linalg.lstsq`). הנגזרת הראשונה והשנייה נגזרות ישירות ממקדמי הפולינום במרכז החלון.
3. **מודל Minimum Jerk ותנועה אנושית:**
   בני אדם מתכננים תנועות נקודה-לנקודה כך שימוזער קצב שינוי התאוצה (Jerk: $\int \|\dddot{x}\|^2 dt$). הפתרון האנליטי הוא פולינום ממעלה 5 המוביל לפרופיל מהירות פעמוני חלק.
4. **חוק שני השלישים (Two-Thirds Power Law):**
   בתנועה אנושית מתקיים קשר הדוק בין עקמומיות המסלול למהירות התנועה: $v(t) \propto \kappa(t)^{-1/3}$. בוטים נאיביים מפרים חוק זה לחלוטין.
